## Внесение в админку

В редакторе публикаций есть поле даты. Для каждой статьи укажите дату из таблицы: сайт покажет её в карточке и статье, а архив отсортирует публикации по этой дате. Админка не даст сохранить две публикации на один день. Старые записи без заданной даты продолжают отображаться по дате создания.

Главная показывает до двух последних публикаций с обложками в левой колонке и до трёх текстовых в правой. Новые десять статей без обложек не заменяют существующие материалы с изображениями.

Обложки оригинальные, в цветах сайта, PNG 1200 × 720 — их можно загружать через редактор публикаций.
